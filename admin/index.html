Connect

Paste a GitHub token once. It stays in this browser only. It is never saved in the repository.

First-time setup
  1. Create a fine-grained token at github.com/settings/personal-access-tokens/new.
  2. Resource owner: assistantinjapan.
  3. Repository access: Only select repositories → assistantinjapan.github.io.
  4. Repository permissions: Contents = Read and write. Nothing else.
  5. Choose an expiration, generate the token, and paste it here.
